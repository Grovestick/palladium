The server.

One installer for Windows, one container for Linux. It reads the folders you point it at and serves what it finds to a browser, a phone and a television on your own network.

Installing it

  • Windows will say it does not recognise the program - the build is not signed yet. Compare the SHA-256 above if you want to be sure, then choose More info and Run anyway.
  • It installs for your account alone. No administrator, no service, nothing added to the system.
  • Point it at your folders on first run. The first scan takes a few minutes and the artwork arrives as it goes.
  • It upgrades in place: settings, invitations and the index are kept, and the program tells you when a new build is out.

On Linux, in a container

The same server, with ffmpeg already inside it. Everything it writes lives in /data; your films are mounted read-only.

services:
  palladium:
    image: ghcr.io/grovestick/palladium:latest
    ports: ["8765:8765"]
    environment: [TZ=Europe/Stockholm]
    volumes:
      - palladium-data:/data
      - /srv/films:/media/films:ro
      - /srv/series:/media/series:ro
    devices: ["/dev/dri:/dev/dri"]   # Intel Quick Sync, optional
    restart: unless-stopped

volumes: { palladium-data: }
  • Set a password on first run. Without one, everybody on that network is treated as the owner.
  • Conversions run on the processor unless you pass a card through. Quick Sync through /dev/dri; an NVIDIA card through the NVIDIA container toolkit and gpus: all.
  • A container is also the sensible second machine: point it at your main server and it keeps copies of what is being watched.

Then

  • Open the address the tray icon shows, from any machine in the house.
  • Install it a second time on another computer and set that one to follow this one: it keeps copies of what is being watched and answers when this machine is off. Settings - Follow another server, on the second machine.
  • Install the app on a phone or a television.
